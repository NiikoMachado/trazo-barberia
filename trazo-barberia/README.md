# TRAZO Barbería — primera demo de Negocio IA

Sitio de portfolio para una barbería ficticia. Creado con HTML, CSS y JavaScript, sin frameworks, instalaciones ni herramientas de pago. Diseño adaptable a celular, tablet y computadora.

**Para empezar:** descomprimí la carpeta y abrí `index.html` en tu navegador. Para aprender, editar y publicar, seguí `GUIA-PASO-A-PASO.md`.

## Archivos

| Archivo | Qué hace |
| --- | --- |
| `index.html` | Contenido: títulos, servicios, precios, galería, horarios y contacto. |
| `styles.css` | Diseño: colores, tipografías, tamaños y adaptación a cada pantalla. |
| `script.js` | Comportamiento: menú móvil, consulta simulada y copia del mensaje. |
| `assets/` | Fotografías y tipografías locales. |
| `GUIA-PASO-A-PASO.md` | Guía para abrir, personalizar, publicar y presentar la demo. |
| `CREDITOS.md` | Fuentes de las fotos y licencias de las tipografías. |

## Qué funciona

- Navegación entre secciones y menú desplegable en pantallas pequeñas.
- Botones de reserva que abren una **simulación**.
- Selección del servicio y generación de una consulta para copiar.
- Cierre mediante botón, tecla Escape o clic fuera de la ventana.
- Enlace al barrio Cordón en Google Maps, sin atribuir una dirección a un comercio real.
- Navegación con teclado, foco visible y preferencia de movimiento reducido.
- Fotos y fuentes locales: la página no las descarga de terceros al abrirse.

## Alcance

TRAZO es un concepto ficticio. Precios y horarios son ejemplos; las fotos son referencias de Unsplash, no trabajos ni instalaciones de TRAZO. La demo no recibe reservas, envía mensajes, cobra ni almacena datos de visitantes. El sitio no incluye seguimiento propio; el proveedor de alojamiento puede mantener sus registros técnicos habituales.

GitHub Pages se propone para mostrar este proyecto de portfolio. Antes de convertirlo en un sitio operativo de un cliente, elegí un alojamiento compatible con ese uso y reemplazá los datos de ejemplo con información autorizada.

No hay compilación ni comandos obligatorios: subí el contenido de esta carpeta a la raíz de un repositorio público y publicá desde `main` → `/(root)`.

## Personalización

Podés adaptar el código para tu portfolio y proyectos de clientes. Las fotografías y fuentes conservan sus licencias; revisá `CREDITOS.md`. No vendas las fotografías como archivos independientes.
